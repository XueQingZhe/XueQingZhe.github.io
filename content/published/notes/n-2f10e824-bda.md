云的本质是：**在 3D 空间中，哪里有介质，有多少**。
体积雾用的是 `exp(-height) * noise`，很粗糙。云需要更精确地描述"蓬松感"和"层次感"，工业标准答案是**两层噪声 + Weather Map 控制**。需要**离线预计算**两张 3D Texture。

# 球壳步进范围判断

**普通的步进范围限制是进行AABB的范围来判断，但是球壳范围判断会复杂一些**
**射线上的某个点的表达式是：**

$$
r(t) = o + t·d
$$

**那么假设点打在了球壳上，那么就会有：**

$$
|O + D·t − C|² = r²
$$

- C是表示球心
- r则是半径
- D是步进单位
- t是步进次数

**球壳上的点到球心的距离是r，也就是半径，根据这个限定条件，就可以求出t**

**因为原点O表示相机位置，C是球心位置，这里可以先进行简化，直接可以合并成相机到球心的距离**

$$
L=O-C
$$

$$
|L + D·t|² = r²
$$

**然后就是展开化简**

$$
L·L + 2t(D·L) + t²(D·D)= r²
$$

**然后移项，这样就得到了关于t的**

$$
(D·D)·t² + 2(D·L)·t + (L·L − r²) = 0
$$

**这里因为D是单位向量，所以平方之后直接是1了，现在的形式和下面的形式类似，那么就是求方程解**

$$
t² + 2bt + c = 0
$$

**最后t的表达式就是，这里需要限定b² − c > 0**

$$
t = −b ± \sqrt{(b² − c)}
$$

**这里把b和c代入就可以求得t的具体值，这两个值表示入球点和出球点**

# CloudShadpeNoise

## FBM

FBM 全称 **Fractional Brownian Motion**，分形布朗运动，来自数学里对自然界随机现象的建模。
***直觉理解***
自然界的很多东西都有**多尺度的细节**：
山脉有大山脉，大山脉上有小山丘，小山丘上有石头，石头上有纹路——**每个尺度上都有相似的粗糙感**。
云也一样：大团云里有中等云块，中等云块上有小蓬松结构。
比如说单层 Worley 只有一个尺度，看起来太规则。FBM 就是**把多个尺度叠加**来模拟这种自然感。

```c
fbm = noise(p * 1.0) * 0.500   // 低频：大结构，权重高
    + noise(p * 2.0) * 0.250   // 中频：中结构，权重中
    + noise(p * 4.0) * 0.125   // 高频：小细节，权重低
```

# 比尔-朗伯散射和简化

## 标准的比尔-朗伯

**标准的比尔朗伯，是指数衰减的，意思是光在介质中传播是指数衰减，这跟密度有关**
![](/published-assets/0406a62e75a5bc571f7c4fe4d44aea28a40046cc807d7ccff8a66ef99e6cbb9d.webp)
**因为是光线步进，那么每次步进的光线衰减的计算代码是这样的**

```c
d = exp(-σ * stepSize) // σ 是消光系数
// 转换成下面的代码
float extinctionCoeff = density * _Extinction;
float stepTransmittance = exp(-extinctionCoeff * stepSize);
```

**每次步进的衰减权重有了，然后进行累积就得到整体的衰减权重**

```c
transmittance(累积) = exp(-σ₁s) * exp(-σ₂s) * ...
// 透射率累积 换成代码也就是
transmittance *= stepTransmittance;
```

## 简化

**对于标准的比尔-朗伯累积的我是这样理解的：**

$$
每步的贡献 = 基础权重 × 密度
$$

```c
// 这里对应
基础权重 = stepSize  （这一步覆盖的空间厚度）
密度     = 采样得到的 σ（独立的，每步不同）
```

**因为介质不均匀，这表示在每层的stepSize是不是均匀分布的，所以基础权重采用的指数衰减，也就是：**

```c
d = exp(-σ * stepSize) 
```

**那么精简的话就直接假设是均匀分布就行了，如果理解成近似均匀介质，那么每层的基本权重也就是下面这样**

```c
d ≈ density * stepSize （线性近似）
// 当然这里可以加上消光系数
d ≈ density * stepSize * _Extinction（线性近似）
```

**因为现在每层的基本权重相，因为现在衰减只和密度相关，而密度增加透射率减小所以效果是相反的，所以要先翻转，那么每次步进的衰减比例就是saturate(1.0 - d)**

```c
float d = density * stepSize * _Extinction;
float stepTransmittance = saturate(1.0 - d);
transmittance *= stepTransmittance;
```

**关于1.0 - d这里其实容易产生负值，虽然钳制可以解决，但是精度会差，2022官方是算法这里将这里变成加法计算，先直接计算吸收率，然后翻转就可以得到透射率**
![](/published-assets/3ca0f5d285d4629db10bf4972760e9c0e3c1a9fc3519a1d1d258b80056d312b7.webp)
**散射率累积就是1-吸收率**

```c
// 初始值
float light_absorption = 0f；
float d = density * stepSize * _Extinction;
// 吸收比例累积
light_absorption += d * (1.0 - light_absorption);
// 透射率累积
transmittance = 1 - light_absorption；
```

```c
    [Header("六条 fade 渐变,编辑时用,运行时不再直接采样")]
    public Gradient stratusBottom       = LinearGradient(0f, 0f, 0.03f, 1f);
    public Gradient stratusTop          = LinearGradient(0.15f, 1f, 0.25f, 0f);
    public Gradient stratocumulusBottom = LinearGradient(0.03f, 0f, 0.15f, 1f);
    public Gradient stratocumulusTop    = LinearGradient(0.35f, 1f, 0.65f, 0f);
    public Gradient cumulusBottom       = LinearGradient(0.1f, 0f, 0.25f, 1f);
    public Gradient cumulusTop          = LinearGradient(0.6f, 1f, 0.95f, 0f);

    [Header("烘焙设置")]
    public int resolution = 128;   // 现在是二维 LUT 的边长,不再是"6行"的那个128

    // 运行时资源:resolution × resolution,单通道,x=cloudType, y=heightFraction
    public Texture2D profileLUT { get; private set; }

    bool isDirty = true;

    static Gradient LinearGradient(float t0, float v0, float t1, float v1)
    {
        var g = new Gradient();
        g.mode = GradientMode.Blend;
        g.SetKeys(
            new[]
            {
                new GradientColorKey(new Color(v0, v0, v0), t0),
                new GradientColorKey(new Color(v1, v1, v1), t1)
            },
            new[]
            {
                new GradientAlphaKey(1f, 0f),
                new GradientAlphaKey(1f, 1f)
            });
        return g;
    }

    void OnEnable()  { Instance = this; Bake(); }
    void OnDisable() { if (Instance == this) Instance = null; }
    void OnValidate() { isDirty = true; }

    void Update()
    {
        if (isDirty) { Bake(); isDirty = false; }
    }

    public Gradient[] Gradients => new[]
    {
        stratusBottom, stratusTop,
        stratocumulusBottom, stratocumulusTop,
        cumulusBottom, cumulusTop
    };

 
    // 原来 GetHeightGradient 的混合逻辑,现在只在烘焙时跑一次,不再进 shader
    public float EvaluateHeightGradient(float heightFraction, float cloudType)
    {
        var g = Gradients;
        float topType    = Mathf.Clamp01(cloudType);
        float bottomType = Mathf.Clamp01(cloudType);

        float stratusBottomFade       = g[0].Evaluate(heightFraction).r;
        float stratusTopFade          = g[1].Evaluate(heightFraction).r;
        float stratocumulusBottomFade = g[2].Evaluate(heightFraction).r;
        float stratocumulusTopFade    = g[3].Evaluate(heightFraction).r;
        float cumulusBottomFade       = g[4].Evaluate(heightFraction).r;
        float cumulusTopFade          = g[5].Evaluate(heightFraction).r;

        // float t1 = Mathf.Clamp01(topType * 2f);
        // float t2 = Mathf.Clamp01((topType - 0.5f) * 2f);
        float t1 = Mathf.SmoothStep(0f, 1f, Mathf.Clamp01(topType * 2f));
        float t2 = Mathf.SmoothStep(0f, 1f, Mathf.Clamp01((topType - 0.5f) * 2f));

        // float topGradient =  Mathf.Lerp(stratusTopFade,  Mathf.Max(stratusTopFade, stratocumulusTopFade), t1);
        // topGradient =  Mathf.Lerp(topGradient,  Mathf.Max(topGradient, cumulusTopFade), t2);

        float topGradient = Mathf.Lerp(
            Mathf.Lerp(stratusTopFade, stratocumulusTopFade, t1),
            cumulusTopFade, t2);

        // float b1 = Mathf.Clamp01(bottomType * 2f);
        //float b2 = Mathf.Clamp01((bottomType - 0.5f) * 2f);
        float b1 = Mathf.SmoothStep(0f, 1f, Mathf.Clamp01(bottomType * 2f));
        float b2 = Mathf.SmoothStep(0f, 1f, Mathf.Clamp01((bottomType - 0.5f) * 2f));

        // float  bottomGradient = Mathf.Lerp(stratusBottomFade,  Mathf.Max(stratusBottomFade, stratocumulusBottomFade), b1);
        // bottomGradient = Mathf.Lerp(bottomGradient,  Mathf.Max(bottomGradient, cumulusBottomFade), b2);

        float bottomGradient = Mathf.Lerp(
            Mathf.Lerp(stratusBottomFade, stratocumulusBottomFade, b1),
            cumulusBottomFade, b2);

        return Mathf.Clamp01(topGradient * bottomGradient);
    }
    
    public void Bake()
    {
        if (profileLUT == null || profileLUT.width != resolution || profileLUT.height != resolution)
        {
            if (profileLUT != null) DestroyImmediate(profileLUT);
            profileLUT = new Texture2D(resolution, resolution, TextureFormat.R8, false);
            profileLUT.wrapMode = TextureWrapMode.Clamp;
            profileLUT.filterMode = FilterMode.Bilinear;
        }

        for (int y = 0; y < resolution; y++)
        for (int x = 0; x < resolution; x++)
        {
            float heightFraction = y / (float)(resolution - 1);
            float cloudType      = x / (float)(resolution - 1);
            float v = EvaluateHeightGradient(heightFraction, cloudType);
            profileLUT.SetPixel(x, y, new Color(v, v, v, v));
        }
        profileLUT.Apply();
    }
}
```

## GenerateWeatherMap

**这里ComputerShader其实就是生成2D的PerlinNoise来作为WeatherMap**

```c
#pragma kernel GenerateWeatherMap

RWTexture2D<float4> _WeatherMap;
int _Resolution;
float _WeatherMapScale;
float _CoverageBias;
float _CoverageScale;
float _CloudTypeBias;
float _CloudTypeScale;
float _CirrusCoverageBias;
float _CirrusCoverageScale;
float _CirrusTypeBias;
float _CirrusTypeScale;
float _Seed;

// ============================================================
// 整数 hash:任意大坐标下精度稳定
// ============================================================
float hash2(float2 p, float seed)
{
    uint2 q = uint2(int2(floor(p)) + 32768);
    uint h = q.x * 1664525u + q.y * 1013904223u;
    h += (uint)(seed * 373.0);          // seed 混入整数域
    h = (h ^ (h >> 16)) * 2654435769u;
    h = h ^ (h >> 16);
    return float(h) * (1.0 / 4294967295.0);   // [0, 1]
}

float PerlinNoise(float2 p, float seed)
{
    float2 i = floor(p);
    float2 f = frac(p);
    float2 u = f * f * (3.0 - 2.0 * f);

    // hash 出角度 -> 单位梯度向量,天然归一化,
    float a00 = hash2(i + float2(0, 0), seed) * 6.2831853;
    float a10 = hash2(i + float2(1, 0), seed) * 6.2831853;
    float a01 = hash2(i + float2(0, 1), seed) * 6.2831853;
    float a11 = hash2(i + float2(1, 1), seed) * 6.2831853;

    float result = lerp(
        lerp(dot(float2(cos(a00), sin(a00)), f - float2(0, 0)),
             dot(float2(cos(a10), sin(a10)), f - float2(1, 0)), u.x),
        lerp(dot(float2(cos(a01), sin(a01)), f - float2(0, 1)),
             dot(float2(cos(a11), sin(a11)), f - float2(1, 1)), u.x),
        u.y
    );
    return result * 0.5 + 0.5;
}

// 旋转矩阵(约36.87度,octave 间去相关)
static const float2x2 rot = float2x2(0.80, 0.60, -0.60, 0.80);

float fbm(float2 p, int octaves, float lacunarity, float gain)
{
    float value = 0.0;
    float amplitude = 0.5;
    float2 shift = float2(100.0, 100.0);

    [unroll]
    for (int i = 0; i < 4; i++)
    {
        if (i >= octaves) break;
        value += PerlinNoise(p, _Seed + float(i)) * amplitude;
        // 每层旋转 + 偏移打破轴向对称;大坐标对整数 hash 无害
        p = mul(rot, p) * lacunarity + shift;
        amplitude *= gain;
    }
    return value;
}

[numthreads(8, 8, 1)]
void GenerateWeatherMap(uint3 id : SV_DispatchThreadID)
{
    float2 uv = float2(id.xy) / float(_Resolution);
    float2 worldXZ = (uv - 0.5) * _WeatherMapScale;

    // R:Coverage(Domain Warping + 旋转 fBm)
    float2 q = float2(
        fbm(worldXZ * _CoverageScale + float2(0.0, 0.0), 3, 2.0, 0.5),
        fbm(worldXZ * _CoverageScale + float2(5.2, 1.3), 3, 2.0, 0.5)
    );
    q = q * 2.0 - 1.0;
    float coverage = fbm((worldXZ + q * 2.0) * _CoverageScale, 4, 2.0, 0.5);
    coverage = saturate(coverage + 0.2 + _CoverageBias);

    // G:CloudType(旋转 fBm)
    float cloudType = fbm(worldXZ * _CloudTypeScale, 3, 2.0, 0.5);
    cloudType = saturate(cloudType +   _CloudTypeBias);
   
    // 改用 smoothstep
    cloudType = smoothstep(0.0, 1.0, cloudType);

    // B:CirrusCoverage
    float2 cq = float2(
        fbm(worldXZ * _CoverageScale * 0.3 + float2(1.7, 9.2), 2, 2.0, 0.5),
        fbm(worldXZ * _CoverageScale * 0.3 + float2(8.3, 2.8), 2, 2.0, 0.5)
    );
    cq = cq * 2.0 - 1.0;
    float cirrusCoverage = fbm((worldXZ + cq * 1.5) * _CirrusCoverageScale, 3, 2.0, 0.5);
    cirrusCoverage = saturate(cirrusCoverage + 0.2 + _CirrusCoverageBias * 0.5);

    // A:CirrusType
    float cirrusType = fbm(worldXZ * _CirrusTypeScale * 0.2, 2, 2.0, 0.5) - 0.5;
    cirrusType = saturate(cirrusType + _CirrusTypeBias);

    _WeatherMap[id.xy] = float4(coverage, cloudType, cirrusCoverage, cirrusType);
}
```

```c#
using UnityEngine;

[ExecuteAlways]
public class WeatherMapGenerator : MonoBehaviour
{
    public static WeatherMapGenerator Instance { get; private set; }

    [Header("Compute Shader")]
    public ComputeShader weatherMapCompute;

    [Header("Resolution")]
    public int resolution = 512;

    [Header("World Scale")]
    public float weatherMapScale = 16000f;

    [Header("Coverage")]
    [Range(-0.5f, 0.5f)] public float coverageBias  = 0f;
    public float coverageScale = 0.0001f;

    [Header("Cloud Type")]
    [Range(-0.5f, 0.5f)] public float cloudTypeBias = 0f;
    public float cloudTypeScale = 0.00003f;

    [Header("Cirrus Coverage")]
    [Range(-0.5f, 0.5f)] public float cirrusCoverageBias  = 0f;
    public float cirrusCoverageScale = 0.0001f;

    [Header("Cirrus Type")]
    [Range(-0.5f, 0.5f)] public float cirrusTypeBias  = 0f;
    public float cirrusTypeScale = 0.00003f;


    [Header("Seed")]
    public float seed = 0f;

    public RenderTexture weatherMap { get; private set; }

    private int kernelIndex;
    private bool isDirty = true;

    // 脏标记缓存
    private float lastCoverageBias;
    private float lastCoverageScale;
    private float lastCloudTypeBias;
    private float lastCloudTypeScale;
    private float lastCirrusCoverageBias;
    private float lastCirrusCoverageScale;
    private float lastCirrusTypeBias;
    private float lastCirrusTypeScale;
    private float lastSeed;

    // 手绘刷新
    public bool isPainterOverride = false; 
    void OnEnable()
    {
        Instance = this;
        InitRT();
        if (weatherMapCompute != null)
            kernelIndex = weatherMapCompute.FindKernel("GenerateWeatherMap");
        isDirty = true;
    }

    void Update()
    {
    
        if (isPainterOverride) return;   // 手绘模式下，跳过自动重新生成
        
        if (coverageBias        != lastCoverageBias       ||
            coverageScale       != lastCoverageScale       ||
            cloudTypeBias       != lastCloudTypeBias       ||
            cloudTypeScale      != lastCloudTypeScale      ||
            cirrusCoverageBias  != lastCirrusCoverageBias  ||
            cirrusCoverageScale != lastCirrusCoverageScale ||
            cirrusTypeBias      != lastCirrusTypeBias      ||
            cirrusTypeScale     != lastCirrusTypeScale     ||
            seed                != lastSeed)
        {
            isDirty = true;
        }

        if (isDirty)
        {
            Generate();
            UpdateLastValues();
            isDirty = false;
        }
    }

    void InitRT()
    {
        if (weatherMap != null) weatherMap.Release();

        weatherMap = new RenderTexture(resolution, resolution, 0, RenderTextureFormat.ARGBHalf);
        weatherMap.enableRandomWrite = true;
        weatherMap.useMipMap = true;
        weatherMap.autoGenerateMips = false;
        weatherMap.filterMode = FilterMode.Trilinear;
        weatherMap.wrapMode = TextureWrapMode.Repeat;
        weatherMap.Create();
    }

    public void Generate()
    {
        if (weatherMapCompute == null || weatherMap == null) return;

        weatherMapCompute.SetTexture(kernelIndex, "_WeatherMap", weatherMap);
        weatherMapCompute.SetInt("_Resolution", resolution);
        weatherMapCompute.SetFloat("_WeatherMapScale", weatherMapScale);

        // Coverage
        weatherMapCompute.SetFloat("_CoverageScale", coverageScale);
        weatherMapCompute.SetFloat("_CoverageBias",  coverageBias);

        // Cloud Type
        weatherMapCompute.SetFloat("_CloudTypeBias",  cloudTypeBias);
        weatherMapCompute.SetFloat("_CloudTypeScale", cloudTypeScale);

        // Cirrus Coverage
        weatherMapCompute.SetFloat("_CirrusCoverageBias",  cirrusCoverageBias);
        weatherMapCompute.SetFloat("_CirrusCoverageScale", cirrusCoverageScale);

        // Cirrus Type
        weatherMapCompute.SetFloat("_CirrusTypeBias",  cirrusTypeBias);
        weatherMapCompute.SetFloat("_CirrusTypeScale", cirrusTypeScale);


        // Seed
        weatherMapCompute.SetFloat("_Seed", seed);

        int threadGroups = Mathf.CeilToInt(resolution / 8f);
        weatherMapCompute.Dispatch(kernelIndex, threadGroups, threadGroups, 1);
        weatherMap.GenerateMips(); 
       // Debug.Log($"weatherMap mipmapCount = {weatherMap.mipmapCount}");  
    }

    void UpdateLastValues()
    {
        lastCoverageBias        = coverageBias;
        lastCoverageScale       = coverageScale;
        lastCloudTypeBias       = cloudTypeBias;
        lastCloudTypeScale      = cloudTypeScale;
        lastCirrusCoverageBias  = cirrusCoverageBias;
        lastCirrusCoverageScale = cirrusCoverageScale;
        lastCirrusTypeBias      = cirrusTypeBias;
        lastCirrusTypeScale     = cirrusTypeScale;
        lastSeed                = seed;
    }

    void OnValidate()
    {
        isDirty = true;
        if (weatherMap == null) InitRT();
    }

    void OnDisable()
    {
        if (weatherMap != null)
        {
            weatherMap.Release();
            weatherMap = null;
        }
    }
}
```

```c#
using UnityEngine;

[ExecuteAlways]
public class WeatherSystem : MonoBehaviour
{
    public static WeatherSystem Instance { get; private set; }

    [Header("References")]
    public WeatherMapGenerator weatherMapGenerator;

    [Header("Weather Presets")]
    public WeatherPreset[] presets;
    public int currentPresetIndex = 0;
    public int targetPresetIndex  = 0;

    [Header("Transition")]
    public float transitionDuration = 10f;
    private float transitionProgress = 1f;
    private WeatherPreset transitionFrom;

    // Feature 读取数据
    public CloudRuntimeData RuntimeData { get; private set; } = new CloudRuntimeData();

    void Awake()
    {
        Instance = this;
    }

    void Start()
    {
        if (presets != null && presets.Length > 0 && presets[currentPresetIndex] != null)
            ApplyPreset(presets[currentPresetIndex]);
    }

    void Update()
    {
        if (transitionProgress < 1f)
        {
            transitionProgress += Time.deltaTime / transitionDuration;
            transitionProgress = Mathf.Clamp01(transitionProgress);

            float t = Mathf.SmoothStep(0f, 1f, transitionProgress);
            BlendPresets(transitionFrom, presets[targetPresetIndex], t);

            if (transitionProgress >= 1f)
                currentPresetIndex = targetPresetIndex;
        }
        else
        {
            // 过渡完成后，每帧刷新当前预设（编辑器和运行时都生效）
            if (presets != null && presets.Length > 0 && presets[currentPresetIndex] != null)
                ApplyPreset(presets[currentPresetIndex]);
        }
        // 每帧更新 RT 引用（RT 可能被重新创建）
        if (weatherMapGenerator != null)
            RuntimeData.weatherMap = weatherMapGenerator.weatherMap;
    }

    public void TransitionToWeather(int presetIndex)
    {
        if (presetIndex == targetPresetIndex) return;
        if (presetIndex < 0 || presetIndex >= presets.Length) return;

        transitionFrom        = CreateCurrentSnapshot();
        targetPresetIndex     = presetIndex;
        transitionProgress    = 0f;
    }

    public void SetWeatherImmediate(int presetIndex)
    {
        if (presetIndex < 0 || presetIndex >= presets.Length) return;
        currentPresetIndex = presetIndex;
        targetPresetIndex  = presetIndex;
        transitionProgress = 1f;
        ApplyPreset(presets[presetIndex]);
    }

   void BlendPresets(WeatherPreset from, WeatherPreset to, float t)
    {
        if (from == null || to == null) return;

        // 对流层云
        RuntimeData.cloudBottom          = Mathf.Lerp(from.cloudBottom,          to.cloudBottom,          t);
        RuntimeData.cloudTop             = Mathf.Lerp(from.cloudTop,             to.cloudTop,             t);

        RuntimeData.detailErodeIntensity = Mathf.Lerp(from.detailErodeIntensity, to.detailErodeIntensity, t);
        RuntimeData.cloudColor           = Color.Lerp(from.cloudColor,           to.cloudColor,           t);
 
        // 卷云
        RuntimeData.cirrusBottom    = Mathf.Lerp(from.cirrusBottom,    to.cirrusBottom,    t);
        RuntimeData.cirrusScale     = Mathf.Lerp(from.cirrusScale,     to.cirrusScale,     t);
        RuntimeData.cirrusIntensity = Mathf.Lerp(from.cirrusIntensity, to.cirrusIntensity, t);
        RuntimeData.cirrusAbsorption= Mathf.Lerp(from.cirrusAbsorption,to.cirrusAbsorption,t);
        RuntimeData.cirrusColor     = Color.Lerp(from.cirrusColor,     to.cirrusColor,     t);

        // 地平线参数
        RuntimeData.aerialDensity   = Mathf.Lerp(from.aerialDensity, to.aerialDensity, t);

        RuntimeData.weatherMoveSpeed     = Mathf.Lerp(from.weatherMoveSpeed,     to.weatherMoveSpeed,     t);
        RuntimeData.weatherMoveDirection = Vector2.Lerp(from.weatherMoveDirection, to.weatherMoveDirection, t).normalized;
        // 光照
        RuntimeData.ambientColor          = Color.Lerp(from.ambientColor,          to.ambientColor,          t);
        RuntimeData.ambientIntensity      = Mathf.Lerp(from.ambientIntensity,      to.ambientIntensity,      t);
        RuntimeData.sunIntensity          = Mathf.Lerp(from.sunIntensity,          to.sunIntensity,          t);
```

## WeatherBrush

```c
Shader "Hidden/WeatherBrush"
{
    Properties { _MainTex ("Base", 2D) = "white" {} }
    SubShader
    {
        Tags { "RenderPipeline" = "UniversalPipeline" }
        Cull Off ZWrite Off ZTest Always

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            TEXTURE2D(_MainTex);
            SAMPLER(sampler_MainTex);
            float4 _BrushColor;
            float4 _ChannelMask;   // 画布是灰度单通道编辑模式下，这里恒为(1,1,1,1)即可，留作以后多通道混合画布备用
            float2 _BrushUV;
            float _BrushSize;
            float _BrushHardness;

            struct Attributes { float4 positionOS : POSITION; float2 uv : TEXCOORD0; };
            struct Varyings   { float4 positionCS : SV_POSITION; float2 uv : TEXCOORD0; };

            Varyings vert(Attributes v)
            {
                Varyings o;
                o.positionCS = TransformObjectToHClip(v.positionOS.xyz);
                o.uv = v.uv;
                return o;
            }

            float4 frag(Varyings i) : SV_Target
            {
                float4 baseColor = SAMPLE_TEXTURE2D(_MainTex, sampler_MainTex, i.uv);
                float dist = length(i.uv - _BrushUV);
                float mask = 1.0 - smoothstep(_BrushSize * _BrushHardness, _BrushSize, dist);
                float4 painted = lerp(baseColor, _BrushColor, mask);
                return lerp(baseColor, painted, _ChannelMask);
            }
            ENDHLSL
        }
    }
}
```

## ChannelWriteBack

```c
Shader "Hidden/ChannelWriteBack"
{
    // 写出用：把灰度画布的值，只写回目标通道，其余通道由ColorMask保护不受影响
    Properties
    {
        _MainTex ("Canvas", 2D) = "white" {}
        _ColorMask ("Color Mask", Int) = 8   // 位掩码 R=8 G=4 B=2 A=1
    }
    SubShader
    {
        Tags { "RenderType"="Opaque" }
        ColorMask [_ColorMask]

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            #include "UnityCG.cginc"

            sampler2D _MainTex;

            struct appdata { float4 vertex : POSITION; float2 uv : TEXCOORD0; };
            struct v2f     { float2 uv : TEXCOORD0; float4 vertex : SV_POSITION; };

            v2f vert(appdata v)
            {
                v2f o;
                o.vertex = UnityObjectToClipPos(v.vertex);
                o.uv = v.uv;
                return o;
            }

            fixed4 frag(v2f i) : SV_Target
            {
                float v = tex2D(_MainTex, i.uv).r;   // canvas 是灰度，R即代表该值
                return fixed4(v, v, v, v);           // 四分量都填v，实际写入哪个由ColorMask决定
            }
            ENDHLSL
        }
    }
```

### computerShader

**使用computerShader拿到weatherMap从太阳方向做一次步进来计算得到ShadowMap**

```c
#pragma kernel GenerateCloudShadowMap

RWTexture2D<float> _CloudShadowMap;   // 单通道，存transmittance(0=完全遮挡, 1=完全透光)

Texture2D<float4> _WeatherMap;
SamplerState sampler_WeatherMap;
Texture3D<float4> _ShapeNoiseTex;
SamplerState sampler_ShapeNoiseTex;
Texture2D<float> _HeightProfileLUT;
SamplerState sampler_HeightProfileLUT;

int _ShadowMapResolution;
float _WeatherMapScale;
float _CloudBottom;
float _CloudTop;
float _Coverage;
float _Absorption;
float _ShapeNoiseScale;
float3 _SunDirection;       // 太阳方向(光线传播方向,从太阳射向地面)
float3 _WindDirection;
float _WindSpeed;
float _CurrentTime;
float3 _WeatherMoveDirection;
float _WeatherMoveSpeed;

float remap(float v, float oldMin, float oldMax, float newMin, float newMax)
{
    return newMin + (v - oldMin) / (oldMax - oldMin) * (newMax - newMin);
}

float SampleCloudProfile(float heightFraction, float cloudType)
{
    float2 uv = float2(cloudType, heightFraction);
    return saturate(_HeightProfileLUT.SampleLevel(sampler_HeightProfileLUT, uv, 0));
}

[numthreads(8,8,1)]
void GenerateCloudShadowMap(uint3 id : SV_DispatchThreadID)
{
    float2 uv01 = (id.xy + 0.5) / (float)_ShadowMapResolution;
    float2 worldXZ = (uv01 - 0.5) * _WeatherMapScale;

    float3 rayDir = normalize(-_SunDirection); // 从地面反向朝太阳走
    float3 rayStart = float3(worldXZ.x, _CloudBottom, worldXZ.y);

    float layerThickness = _CloudTop - _CloudBottom;
    float travelDistPerUnitHeight = layerThickness / max(rayDir.y, 0.15); // 太阳低角度时的保护

    static const float stepFractions[6] = { 0.05, 0.15, 0.3, 0.5, 0.7, 0.9 };
    static const float stepWeights[6]   = { 1, 1, 2, 2, 3, 3 };

    float totalDensity = 0;
    float3 windOffset = _WindDirection * _CurrentTime * _WindSpeed;
    float2 weatherOffset = _WeatherMoveDirection.xz * _WeatherMoveSpeed * _CurrentTime;

    [unroll]
    for (int i = 0; i < 6; i++)
    {
        float t = stepFractions[i] * travelDistPerUnitHeight;
        float3 p = rayStart + rayDir * t;

        float heightFraction = saturate((p.y - _CloudBottom) / layerThickness);

        float2 wUV = p.xz / _WeatherMapScale + 0.5 + weatherOffset;
        float4 w = _WeatherMap.SampleLevel(sampler_WeatherMap, wUV, 2);
        float coverage = w.r * _Coverage;
        float cloudType = w.g;

        float profile = SampleCloudProfile(heightFraction, cloudType) * coverage;

        float3 animatedPos = p + windOffset;
        float4 shape = _ShapeNoiseTex.SampleLevel(sampler_ShapeNoiseTex, animatedPos * _ShapeNoiseScale, 1);
        float worleyFBM = shape.g * 0.625 + shape.b * 0.25 + shape.a * 0.125;
        float baseCloud = saturate(remap(shape.r, worleyFBM - 1.0, 1.0, 0.0, 1.0));
        float density = saturate(baseCloud - (1.0 - profile));

        totalDensity += density * stepWeights[i];
    }

    float transmittance = exp(-totalDensity * _Absorption * 0.15); // 归一化系数,跑起来后按效果调
    _CloudShadowMap[id.xy] = saturate(transmittance);
}
```

## ShdowMap的简化

**直接增加Pass，不在进行烘焙ShdowMap，使用少数几次采样来模拟阴影，不需要真的从太阳方向进行步进，也能减少传值**

```c
Pass
{
	Name "ApplyGroundShadow"
	HLSLPROGRAM
	#pragma vertex vert
	#pragma fragment frag
	float _CloudShadowScale;
	
	float4 frag(Varyings input) : SV_Target
	{
		float4 sceneColor = SAMPLE_TEXTURE2D(_MainTex, sampler_MainTex, input.uv);
		float rawDepth = SampleSceneDepth(input.uv);

		// 天空(云自己)不处理，只压暗有真实深度的物体
		bool isSky = false;
		#if defined(UNITY_REVERSED_Z)
			if (rawDepth <= 0.00001) isSky = true;
		#else
			if (rawDepth >= 0.99999) isSky = true;
		#endif
		if (isSky) return sceneColor;

		// 重建世界坐标
		float4 ndc = float4(input.uv * 2.0 - 1.0, rawDepth, 1.0);
		float4 worldPos = mul(_InverseVP, ndc);
		worldPos /= worldPos.w;

		Light mainLight = GetMainLight();
		float3 sunDir = mainLight.direction;

		float layerThickness = _CloudTop - _CloudBottom;
		float2 weatherOffset = _WeatherMoveDirection.xz * _WeatherMoveSpeed * _Time.y;
		float3 windOffset = _WindDirection * _Time.y * _WindSpeed;

		// ===== 3层高度采样，简化路径积分 =====
		const int sampleCount = 3;
		float totalCoverage = 0;
		float totalShapeMod = 0;

		[unroll]
		for (int i = 0; i < sampleCount; i++)
		{
			float heightFraction = (i + 0.5) / (float)sampleCount; // 0.167, 0.5, 0.833 三层
			float sampleHeight = _CloudBottom + heightFraction * layerThickness;
			float heightToSample = sampleHeight - worldPos.y;

			// 沿太阳方向的水平偏移
			float2 offset = sunDir.xz * (heightToSample / max(abs(sunDir.y), 0.15));
			float2 sampleXZ = worldPos.xz + offset;

			// weatherMap coverage
			float2 weatherUV = sampleXZ / _WeatherMapScale * _CloudShadowScale + 0.5 + weatherOffset;
			float coverage = SAMPLE_TEXTURE2D_LOD(_WeatherMap, sampler_WeatherMap, weatherUV, 0).r;
			totalCoverage += coverage;

			// ShapeNoise细节调制(粗mip，单次采样)
			float3 samplePos3D = float3(sampleXZ.x, sampleHeight, sampleXZ.y) + windOffset;
			float4 shape = SAMPLE_TEXTURE3D_LOD(_ShapeNoiseTex, sampler_ShapeNoiseTex, samplePos3D * _ShapeNoiseScale, 2);
			float worleyFBM = shape.g * 0.625 + shape.b * 0.25 + shape.a * 0.125;
			float baseCloud = saturate(worleyFBM * 0.5 + shape.r * 0.5);
			totalShapeMod += baseCloud;
		}

		totalCoverage /= sampleCount;
		totalShapeMod /= sampleCount;

		// ShapeNoise在coverage基础上做浮动，增加细节层次和风动感
		float density = totalCoverage * lerp(0.7, 1.3, totalShapeMod);

		float shadowFactor = lerp(1.0, 1.0 - _CloudShadowStrength, saturate(density));
		sceneColor.rgb *= shadowFactor;

		return sceneColor;
	}
	ENDHLSL
}
```

```c
            bool raySphereIntersect(float3 rayOrigin, float3 rayDir, float3 center, float radius, out float t0, out float t1)
            {
                float3 oc = rayOrigin - center;
                float b = dot(rayDir, oc);
                float c = dot(oc, oc) - radius * radius;
                float disc = b * b - c;
                if (disc < 0) { t0 = -1; t1 = -1; return false; }
                float sqrtDisc = sqrt(disc);
                t0 = -b - sqrtDisc;
                t1 = -b + sqrtDisc;
                return true;
            }

                worldPos /= worldPos.w;

                // {
                //    return float4(0, 0, 0, 1.0);
                // }

                #if defined(UNITY_REVERSED_Z)
                    if (rawDepth <= 0.00001) isSky = true;
                #else
                    if (rawDepth >= 0.99999) isSky = true;
                #endif

                if (!isSky && depth < _CloudBottom * 0.5)   // 近处不透明物挡住,云不可能在其前
                return float4(0, 0, 0, 0);
                // ======== 射线步进 ========
                // 射线终点：worldPos.xyz（当前像素对应的世界坐标）
                // 射线起点：相机世界坐标_WorldSpaceCameraPos（URP内置变量，不需要额外传）
                float3 rayStart = _WorldSpaceCameraPos;
                float3 rayEnd = worldPos.xyz;
                float3 rayDir = normalize(rayEnd - rayStart);

                // //剔除地平线向下的射线
                // if (rayDir.y < -0.001)
                //     return float4(0, 0, 0, 0);

                // 地球中心在相机正下方
                float earthRadius = 6371000.0;
                float3 earthCenter = float3(_WorldSpaceCameraPos.x,  -earthRadius, _WorldSpaceCameraPos.z);

                float t0Inner, t1Inner, t0Outer, t1Outer;
                bool hitInner = raySphereIntersect(rayStart, rayDir, earthCenter, earthRadius + _CloudBottom, t0Inner, t1Inner);
                bool hitOuter = raySphereIntersect(rayStart, rayDir, earthCenter, earthRadius + _CloudTop, t0Outer, t1Outer);
                
               
                // 没打到外球，说明射线向下，不渲染
                if (!hitOuter) return float4(0, 0, 0, 0);
                if (_WorldSpaceCameraPos.y < _CloudBottom && rayDir.y < -0.001)
                return float4(0, 0, 0, 0);

                float tMin, tMax;
                
                if (_WorldSpaceCameraPos.y < _CloudBottom)
                {
                    // 相机在云层下方（最常见）
                    tMin = t1Inner; // 从内球出口进入云层
                    tMax = t1Outer; // 到外球出口离开云层
                }
                else if (_WorldSpaceCameraPos.y > _CloudTop)
                {
                    // 相机在云层上方
                    tMin = t0Outer; // 从外球入口进入云层
                    tMax = t0Inner > 0 ? t0Inner : t1Outer; // 到内球入口或外球出口
                }
                else
                {
                    // 相机在云层内部：起点就是相机自身
                    tMin = 0;                
                    if (rayDir.y >= 0)
                    {
                        // 向上看，终点是外球的出口
                        tMax = t1Outer;
                    }
                    else
                    {
                        // 向下看
                        if (hitInner && t0Inner > 0)
                        {
                            // 如果撞击到了内球（云底下方空间），步进到内球入口为止
                            tMax = t0Inner;
                        }
                        else
                        {
                            // 视线倾斜擦过地平线但没撞到内球的情况，用外球出口兜底
                            tMax = t1Outer;
                        }
                    }
                }      
                
                //保持场景在前，云在后
                if (!isSky)
                {
                    float maxRayDist = length(rayEnd - rayStart);
                    tMax = min(tMax, maxRayDist);
                }
                
                //保持场景在前，云在后
                if (tMax <= tMin) return float4(0, 0, 0, 0);

                if (tMax < 0 || tMin > tMax)
                    return float4(0, 0, 0, 0);
                tMin = max(tMin, 0);

               
                // 限制云的最大可见距离，避免水平视角下步进过于稀疏
                float maxCloudDist = 15000.0;  // 根据你的场景尺度调整
                tMax = min(tMax, tMin + maxCloudDist);

                float3 scatteredLight = float3(0, 0, 0);

                float3 lightDir = mainLight.direction;

                float phase = DualHenyeyGreenstein(cosTheta, _Anisotropy, _SilverIntensity, _SilverSpread);

                // ========== WindOffset ==============
                float3 windOffset       = _WindDirection * _Time.y * _WindSpeed;
                float3 detailWindOffset = _WindDirection * _Time.y * _WindSpeed * 0.4;
                float2 weatherOffset    = _WeatherMoveDirection.xz * _WeatherMoveSpeed * _Time.y;

                // ============ 步进步长参数 ===========
                // int stepCount = 32;
                // float stepSize = (tMax - tMin) / stepCount;
                //float horizonFactor = 1.0 - abs(rayDir.y);
                //int stepCount = (int)lerp(128, 512, horizonFactor);  // 水平视角时步数增加到96
                // 固定每步的世界空间距离
                // float fixedStepSize = 25.0; // 单位：米，根据你的场景尺度调整
                // int stepCount = (int)clamp((tMax - tMin) / fixedStepSize, 32, 512);
                // float stepSize = (tMax - tMin) / stepCount;

                // ========= 步进步长参数 - 穿云判断 =======
                // 判断相机是否在云层内
                bool cameraInCloud = (_WorldSpaceCameraPos.y > _CloudBottom && _WorldSpaceCameraPos.y < _CloudTop);

                // 相机在云内用更小的初始步长
                //float near_step_size = cameraInCloud ? 1.0 : 3.0;
                float near_step_size = 3.0;
                float far_step_size_offset = 60.0;
                float step_adjustment_distance = 16384.0;
                float stepScale = 1.0; 
                float lastStride = 0.0;  
                // ========= 射线步进起点抖动偏移 =======
                float tMinJitter = 0.0;
                if(_UseStepJitter)
                {
                    //float jitter1 = frac(sin(dot(uv, float2(12.9898, 78.233))) * 43758.5453);
                    float2 noiseUV = input.uv * _ScreenParams.xy * _BlueNoiseTex_TexelSize.xy;
                    float jitter = SAMPLE_TEXTURE2D(_BlueNoiseTex, sampler_BlueNoiseTex, noiseUV * _BlueNoiseTileScale).r;
                    //tMinJitter = jitter * near_step_size; 
                    float stepSizeAtTMin = near_step_size + (far_step_size_offset * tMin / step_adjustment_distance);
                    tMinJitter = jitter * stepSizeAtTMin;    // 远处入云时抖动自动放大到 ~60m
                    tMin += tMinJitter;
                }

                // 偏移到初始采样位置系数
                float t = tMin;

                float prevStride = near_step_size;
                [loop]
                for (int i = 0; i < 512; i++)
                {
                  
                    if (t >= tMax) break; // 防御：防止抖动导致最后一步越界超过不透明物体
                    //if (transmittance < 0.01) break;

                    // 当前步长（近处3m，16km处63m）
                    //float stepSize = near_step_size + (far_step_size_offset * t / step_adjustment_distance);

                    float rawStepSize = near_step_size + (far_step_size_offset * t / step_adjustment_distance);
                    float stepSize = lerp(prevStride, rawStepSize, 0.5);
                    float3 samplePos = rayStart + rayDir * t;
                  
                    // ===== 高度梯度(常规版) ===
                    //float heightFraction = saturate((samplePos.y - _CloudBottom) / (_CloudTop - _CloudBottom));
                    // ===== 高度梯度（球壳版）=====
                    float distToCenter = length(samplePos - earthCenter);
                    float heightFraction = saturate((distToCenter - (earthRadius + _CloudBottom)) /  (_CloudTop - _CloudBottom));
                 
                    // 从 Weather Map 采样 cloudType（暂时还没有的话先用全局参数）
                    //float topType = _CloudType; // 之后替换为 weatherMap.b
                    // ================================================
                    // ============== Weather Map 采样 =================
                    // ================================================
                   // float weatherMip = clamp(log2(max(t, 1.0) / maxCloudDist), 0.0, 4.0);
                    float2 weatherUV = samplePos.xz / _WeatherMapScale + 0.5 + weatherOffset;
                    float4 weather = SAMPLE_TEXTURE2D_LOD(_WeatherMap, sampler_WeatherMap, weatherUV, 2);
                    //weather = float4(0.86, 0.9, 0.9, 1);
                    float coverage  = weather.r * _Coverage;
                    float cloudType = weather.g;
                    //return float4(coverage.xxx, 1); // 归一化到可见范围，方便对比亮度
                
                    // TopType 和 BottomType 从 cloudType 派生
                    float topType    = saturate(cloudType);
                    float bottomType = saturate(cloudType * 0.8);

                    // ===============================================================                 
                    // ============ 定义的三类云的垂直基础轮廓 heightGradient ==========
                    // ===============================================================
                  
                   
                    // // 层云 Stratus：从 0.05 开始淡入，0.1 达到最浓；0.15 开始淡出，0.22 彻底消失 (很薄)
                    // float stratusBottomFade = remap(heightFraction, 0, 0.03, 0.0, 1.0);
                    // float stratusTopFade = remap(heightFraction, 0.15, 0.25, 1.0, 0.0);

                    // // 层积云 Stratocumulus：从 0.05 开始淡入，0.15 达到最浓；从 0.35 开始淡出，0.5 彻底消失 (中等)
                    // float stratocumulusBottomFade = remap(heightFraction, 0.03, 0.15, 0.0, 1.0);
                    // float stratocumulusTopFade = remap(heightFraction, 0.35, 0.65, 1.0, 0.0);

                    // // 积云 Cumulus：从 0.05 开始淡入，0.2 达到最浓；从 0.6 开始淡出，0.85 彻底消失 (高耸)
                    // float cumulusBottomFade = remap(heightFraction, 0.1, 0.25, 0.0, 1.0);
                    // float cumulusTopFade = remap(heightFraction, 0.6, 0.95, 1.0, 0.0);

                    // // blend topGradient
                    //float cloudHeightGradient = 0.0;
                    // float t1 = saturate(topType * 2.0);
                    // float t2 = saturate((topType - 0.5) * 2.0);
                    // // float topGradient = lerp(stratusTopFade, max(stratusTopFade, stratocumulusTopFade), t1);
                    // // topGradient = lerp(topGradient, max(topGradient, cumulusTopFade), t2);
                    // float topGradient = lerp(
                    //     lerp(stratusTopFade, stratocumulusTopFade, t1),
                    //     cumulusTopFade,
                    //     t2
                    // );
                    // // blend bottomGradient
                    // float b1 = saturate(bottomType * 2.0);
                    // float b2 = saturate((bottomType - 0.5) * 2.0);
                    // // float  bottomGradient = lerp(stratusBottomFade, max(stratusBottomFade, stratocumulusBottomFade), b1);
                    // // bottomGradient = lerp(bottomGradient, max(bottomGradient, cumulusBottomFade), b2);
                    // float bottomGradient = lerp(
                    //     lerp(stratusBottomFade, stratocumulusBottomFade, b1),
                    //     cumulusBottomFade,
                    //     b2
                    // );
                    // ========= final heightGradient 基本云轮廓 =========
                    //cloudHeightGradient = saturate(topGradient) * saturate(bottomGradient);
                    //cloudHeightGradient = saturate(heightGradient);
                    
                    // 采样HeightProfile
                    float cloudHeightProfile = SampleCloudProfile(heightFraction, cloudType);   // 第0行 = stratusBottom
                    // ======== final 云轮廓 =========
                    float dimensional_profile = saturate(cloudHeightProfile * coverage);
                   
                

                    // ===== 穿云处理1：球形消隐 =====
                    float camSphereMask = 1.0;
                    if (cameraInCloud)
                    {
                        // 采样点到相机的世界空间距离
                        float distToCam = length(samplePos - _WorldSpaceCameraPos);
                        camSphereMask = saturate(distToCam / 80.0);
                    }

                    dimensional_profile *= camSphereMask;

                    // // 一级continue
                    // if (dimensional_profile <= 0.001)
                    // {
                    //     t += stepSize;
                    //     continue; 
                    // }

                    // 一级 continue -改
                    if (dimensional_profile <= 0.05)
                    {
                        lastStride = stepSize * stepScale;
                        t += lastStride;
                        stepScale = min(stepScale * 1.5, 4.0);
                        continue;   // 连续踩空,步子越迈越大,封顶4倍
                    }
                    // 命中云时:
                    if (stepScale > 1.0)
                    {
                        t -= lastStride;  // 回退,找回被大步跳过的云边
                        stepScale = 1.0;
                        t += stepSize * stepScale;    
                        continue;   
                    }
                   

                    // ===============================================================
                    // ============= Cheap 采样（Shape Noise 只读 r 通道）=============
                    // ===============================================================
                    // 只读取 R 通道 (.r)，并且强制走低分辨率的 Mip 1 (最   后一个参数传 1.0)
                    float3 animatedPos = samplePos + windOffset;
                    float cheapShapeR = SAMPLE_TEXTURE3D_LOD(_ShapeNoiseTex, sampler_ShapeNoiseTex, animatedPos * _ShapeNoiseScale, 1.0).r;
                    float cheapCloud = remap(cheapShapeR, -0.5, 1.0, 0.0, 1.0);
                    //  不需计算任何 Worley FBM 直接拿R 通道去碰天气图的边界
                    //float cheapDensity = saturate(dimensional_profile - cheapShapeR);
                    float cheapDensity = saturate(cheapCloud - (1.0 - dimensional_profile));
                    if (cheapDensity <= 0.0)
                    {
                        t += stepSize;
                        continue;
                    }
                    // ===============================================================
                    // ================== 一级 Full 采样（baseCloud）==================
                    // ===============================================================
                    float shapeMip  = clamp(log2(max(t, 1.0) / maxCloudDist), 0.0, 4.0);
                    float detailMip = min(shapeMip, 1.0);   // detail 只有 32³,高 mip 全是灰,封顶 1
      
                    float4 shape = SAMPLE_TEXTURE3D_LOD(_ShapeNoiseTex, sampler_ShapeNoiseTex, animatedPos * _ShapeNoiseScale, 2);
                    float worleyFBM = shape.g * 0.625 + shape.b * 0.25 + shape.a * 0.125;
                    float baseCloud = remap(shape.r, worleyFBM - 1.0, 1.0, 0.0, 1.0);
                    baseCloud = saturate(baseCloud);

                    // 乘上高度梯度
                    float base_cloud_density = saturate(baseCloud - (1.0 - dimensional_profile));
                   
                    //base_cloud_density = saturate(pow(base_cloud_density,2) * 5);
                    // 二级continue 空区域：直接跳过
                    if (base_cloud_density <= 0.01)
                    {
                        t += stepSize;
                        continue;
                    }
        
                    // ===============================================================
                    // ================= 二级Full 采样（Detail + Curl）================
                    // ===============================================================

                    float3 detailAnimatedPos = samplePos + detailWindOffset;
                    // curl Noise
                    float2 curlUV = samplePos.xz * _CurlScale;
                    float2 curl = SAMPLE_TEXTURE2D(_CurlNoiseTex, sampler_CurlNoiseTex, curlUV).rg * 2.0 - 1.0;
                    detailAnimatedPos += float3(curl.x, 0, curl.y) * _CurlStrength;
                    if (t < maxCloudDist - 1000.0)

                        detailFBM = detail.r * 0.625 + detail.g * 0.25 + detail.b * 0.125;

                        //float detailFade = saturate((maxCloudDist - 500 - t) / 1000.0);   // 最后 1km 渐变
                
                    }
                    else
                    {   // 降LOD
                        float3 detail = SAMPLE_TEXTURE3D_LOD(_DetailNoiseTex, sampler_DetailNoiseTex, detailAnimatedPos * _DetailNoiseScale, 2).rgb;
                        detailFBM = detail.r * 0.625 + detail.g * 0.25 + detail.b * 0.125;              
                    }
                   
                    // height Detail Blend Tpye
                    float tpye1 = lerp(detailFBM, (1.0 - detailFBM), saturate( heightFraction * heightFraction));
                    float tpye2 = lerp(detailFBM, (1.0 - detailFBM), saturate( heightFraction * 8));
                    float tpye3 = max(tpye1, tpye2);
                    float tpye4 = min(tpye1, tpye2);

                    float t1 = saturate(_DetailErodeType * 3.0);
                    float t2 = saturate((_DetailErodeType - 0.33) * 3.0);
                    float t3 = saturate((_DetailErodeType - 0.66) * 3.0);
                    float heightDetailBlend = lerp(lerp(lerp(tpye1, tpye2, t1), tpye3, t2), tpye4, t3);

                    float oneMinusShape = 1.0 - base_cloud_density;                          
                    float detailErodeWeight = oneMinusShape * oneMinusShape * oneMinusShape;
                    base_cloud_density = base_cloud_density - (1.0 - heightDetailBlend) * detailErodeWeight  * _DetailErodeIntensity;
                   
                    float density = saturate(base_cloud_density);  
                    density = max(0, density - _DensityThreshold);

                    // ===== 穿云处理2：智能近剪裁面消隐 =====
                    // 如果相机在云外，保持短距离消隐避免硬切面；在云内时，放开限制（只保留极其微小的裁剪面遮罩）
                    float fadeDist = cameraInCloud ? 0.5 : 15.0;
                    float nearFade = saturate(t / fadeDist);
                    density *= nearFade;

                    // 三级continue 空区域：直接跳过
                    if (density <= 0)
                    {
                        t += stepSize;
                        continue;
                    }

                    float densityAlongView = 1.0 - transmittance;
                    // 光照透射率（这个点能接收多少光）
                    //float lightT = sampleLightTransmittance1(samplePos, dimensional_profile,densityAlongView);
                    //float lightT = sampleLightTransmittance(samplePos, dimensional_profile);
                    
                    float lightT = sampleLightTransmittance2(samplePos, earthCenter, earthRadius, densityAlongView);
                    float powderEffect = 1.0 - exp(-density * stepSize * 2.0) * _PowderEffectIntensity;
                 
                    // powderEffect = lerp(1.0, powderEffect, saturate(dimensional_profile)) *0.1;
                    //lightT *= powderEffect;
                    // // In-Scatter Probability (搁置废弃)
                    // float depth_probability = 0.05 + pow(density, remap(heightFraction, 0.3, 0.85, 0.5, 2.0));
                    // float vertical_probability = pow(remap(heightFraction, 0.07, 0.14, 0.1, 1.0), 0.8);
                    // float inScatterProb = depth_probability * vertical_probability;
                    // float inScatterProb = 1.0 - exp(-density * stepSize * _Extinction);       
                                    
                    // 直接散射 Direct Scattering
                    float primary_attenuation   = lightT;                       // 透射率
                    float secondary_attenuation = pow(lightT, 0.25) * 0.7;      // 衰减更慢的版本
                    float attenuation = max(primary_attenuation, remap(cosTheta, 0.7, 1.0, primary_attenuation, secondary_attenuation));
                    attenuation = attenuation * lerp(1.0, powderEffect, saturate(1.0 - attenuation));
                    float directScatter = phase * attenuation;
                    float3 directLight  = directScatter * mainLight.color.rgb ;
            
                    // Multiple Scattering
                    float ms_volume = remap(dimensional_profile * stepSize, 0.1, 1.0, 0.0, 1.0) * pow(coverage * cloudType, 0.25) ;
             
                 
                    //float ms_volume = remap(dimensional_profile * stepSize, 0.1, 1.0, 0.0, 1.0);
                    //float ms_volume = remap(heightFraction, 0.1, 1.0, 0.0, 1.0);
                    ms_volume *= pow(lightT, _MultipleScatteringDepthPower);
                    ms_volume *= pow(heightFraction, _MultipleScatteringHeightPower);
                    float secondaryPhase = HenyeyGreenstein(cosTheta, 0.3);
                    float3 multipleScatterLight = ms_volume * secondaryPhase * mainLight.color.rgb * _MultipleScatterIntensity ;
                    
                       
                    // ambient Scatter 环境散射
                    //float ambientScatter = pow(1.0 - dimensional_profile, 0.5);
                    //float ambientScatter = lerp(_AmbientFloor, 1.0, pow(1.0 - dimensional_profile, 0.5)) * lerp(_AmbientBottomStrength, 1.0, heightFraction);
                    float ambientScatter = lerp(_AmbientBaseIntensity, 1.0, smoothstep(_AmbientFloor, 1.0, 1.0 - dimensional_profile)) * lerp(_AmbientBottomStrength, 1.0, heightFraction);                  
                    float3 ambientLight = ambientScatter * ambient;
                    //float powderEffect = 1.0 - exp(-density * stepSize * 2.0) * _PowderEffectIntensity;
                    //ambientLight = ambientLight + ambientLight * powderEffect;
                    // aerial Color 极远处颜色渐变
                    float aerial = exp(-t * _AerialDensity);  // 0.00005~0.0002 
                    float3 aerialColor = lerp(_HorizonTint.rgb, _CloudColor.rgb, aerial);
                                    
                    // 累积散射光
                    float extinctionCoeff = density * _Extinction;
                    float stepTransmittance = exp(-extinctionCoeff * stepSize);
                    float integrationFactor = (extinctionCoeff > 0.0001) ? (1.0 - stepTransmittance) / extinctionCoeff  : stepSize;

                    scatteredLight += transmittance * (directLight + multipleScatterLight + ambientLight)  * density  * _ScatterIntensity  * integrationFactor * aerialColor  ;
                 
            
               
                    transmittance *= stepTransmittance;                                                        
                    t += stepSize;
                    prevStride = stepSize;
                    
                    if (transmittance < 0.01) break;  // early exit 
                }
                scatteredLight *= _CloudColor.rgb;
                // ===============================================================
                // =========================== 卷云层 =============================
                // ===============================================================
                //if (rayDir.y > 0.0001)  // 只处理向上看的射线
                //最后一步进行单次采样卷云
                if (transmittance > 0.01) 
                {
                    float cirrusHeight = _CirrusBottom;
                    float cirrusT = 0;
                    if(cirrusHeight - rayStart.y > 0)
                    {
                        cirrusT = -(cirrusHeight - rayStart.y) / (rayDir.y + 0.00001);
                    }
                    cirrusT = (cirrusHeight - rayStart.y) / (rayDir.y + 0.00001);
                    //float cirrusHeight = min(_CirrusBottom, _CloudTop - 200);
                    bool canRenderCirrus = (abs(rayDir.y) > 1e-4) && (cirrusT > 0) && (transmittance > 0.01);
                   
                    // 如果未射向天空（撞到了非天空物体，如地面），需确保卷云在物体前面
                    if (!isSky)
                    {
                        float maxRayDist = min(length(rayEnd - rayStart),maxCloudDist);
                        if (cirrusT > maxRayDist) canRenderCirrus = false;
                    }
                    if (canRenderCirrus)
                    {
                    
                        float3 cirrusPos = rayStart + rayDir * cirrusT;

                        float2 weatherUV = saturate(cirrusPos.xz / _WeatherMapScale + 0.5);
                        float4 weather = SAMPLE_TEXTURE2D(_WeatherMap, sampler_WeatherMap, weatherUV);

                        float cirrusCoverage = weather.b * _CirrusCoverage;
                        float cirrusType = weather.a;
                        
                       
                        if (cirrusCoverage > 0.05)
                        {
                            // Curl Noise 扰动
                            float2 curlUV = cirrusPos.xz * _CurlScale;
                            float2 curl = SAMPLE_TEXTURE2D(_CurlNoiseTex, sampler_CurlNoiseTex, curlUV).rg * 2.0 - 1.0;

                            float2 curlOffset = curl * _CurlStrength;
                            float2 windUVOffset = _WindDirection.xz * _Time.y * _WindSpeed * 0.001;

                            float2 cirrusUV = (cirrusPos.xz  + curlOffset) * _CirrusScale + windUVOffset;
    
                            // 采样三通道（streaky/wispy/round 分别存在 rgb）
                            float3 cirrusSample = SAMPLE_TEXTURE2D(_CirrusNoiseTex, sampler_CirrusNoiseTex, cirrusUV).rgb;
                            float cr_streaky = cirrusSample.r;
                            float cr_wispy   = cirrusSample.g;
                            float cr_round   = cirrusSample.b;
                            // Coverage 控制
                            float cirrusDensity = remap(cirrusType, 0.5, 1.0, remap(cirrusType, 0.0, 0.5, cr_streaky, cr_wispy), cr_round);
                            cirrusDensity = pow(max(cirrusDensity, 0.0), 1.0 - remap(cirrusCoverage, 0.0, 1.0, -0.9, 0.9));
                            cirrusDensity *= remap(pow(cirrusCoverage, 3.0), 0.0, 0.5, 0.0, 1.0);
                            cirrusDensity = saturate(cirrusDensity);
                            // 光相位-卷云前向散射很强
                            

                            if (cirrusDensity> 0)
                            {                        
                               
                                float cirrusPhase = HenyeyGreenstein(cosTheta, 0.8);
                                if(cirrusPhase < 0) continue;
                                // 光源采样 4 次体积采样
                                float cirrusLightT = sampleCirrusLightTransmittance(cirrusPos, windUVOffset, curlOffset);
                                
                                float3 cirrusLight = mainLight.color.rgb * cirrusDensity * cirrusPhase * cirrusLightT * _CirrusIntensity * _CirrusColor;
                                
                                // 作为 "the last sample" 融入整体的 transmittance
                                scatteredLight += transmittance * cirrusLight;
                            
                                // 人为视线方向的透射率扣减（卷云对后续天空/背景的遮挡）
                                // 视线方向的虚拟步长设为 200.0，与你的光照步进基准保持一致
                                float viewStepSize = 200.0; 
                                float cirrusViewExtinction = cirrusDensity * _CirrusAbsorption;
                                // 扣减全局透射率，让蓝天和星星能被正确挡住
                                transmittance *= exp(-cirrusViewExtinction * viewStepSize);                           
                            }
                        }
                                    
                    }
                }
               
                return float4(scatteredLight, 1.0 - transmittance);          
                
            }
            ENDHLSL
        }

        Pass
        {
            Name "ApplyGroundShadow"
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            float _CloudShadowScale;
            
            float4 frag(Varyings input) : SV_Target
            {
                float4 sceneColor = SAMPLE_TEXTURE2D(_MainTex, sampler_MainTex, input.uv);
                float rawDepth = SampleSceneDepth(input.uv);

                // 天空(云自己)不处理，只压暗有真实深度的物体
                bool isSky = false;
                #if defined(UNITY_REVERSED_Z)
                    if (rawDepth <= 0.00001) isSky = true;
                #else
                    if (rawDepth >= 0.99999) isSky = true;
                #endif
                if (isSky) return sceneColor;

                // 重建世界坐标
                float4 ndc = float4(input.uv * 2.0 - 1.0, rawDepth, 1.0);
                float4 worldPos = mul(_InverseVP, ndc);
                worldPos /= worldPos.w;

                Light mainLight = GetMainLight();
                float3 sunDir = mainLight.direction;

                float layerThickness = _CloudTop - _CloudBottom;
                float2 weatherOffset = _WeatherMoveDirection.xz * _WeatherMoveSpeed * _Time.y;
                float3 windOffset = _WindDirection * _Time.y * _WindSpeed;

                // ===== 3层高度采样，简化路径积分 =====
                const int sampleCount = 3;
                float totalCoverage = 0;
                float totalShapeMod = 0;

                [unroll]
                for (int i = 0; i < sampleCount; i++)
                {
                    float heightFraction = (i + 0.5) / (float)sampleCount; // 0.167, 0.5, 0.833 三层
                    float sampleHeight = _CloudBottom + heightFraction * layerThickness;
                    float heightToSample = sampleHeight - worldPos.y;

                    // 沿太阳方向的水平偏移
                    float2 offset = sunDir.xz * (heightToSample / max(abs(sunDir.y), 0.15));
                    float2 sampleXZ = worldPos.xz + offset;

                    // weatherMap coverage
                    float2 weatherUV = sampleXZ / _WeatherMapScale * _CloudShadowScale + 0.5 + weatherOffset;
                    float coverage = SAMPLE_TEXTURE2D_LOD(_WeatherMap, sampler_WeatherMap, weatherUV, 0).r;
                    totalCoverage += coverage;

                    // ShapeNoise细节调制(粗mip，单次采样)
                    float3 samplePos3D = float3(sampleXZ.x, sampleHeight, sampleXZ.y) + windOffset;
                    float4 shape = SAMPLE_TEXTURE3D_LOD(_ShapeNoiseTex, sampler_ShapeNoiseTex, samplePos3D * _ShapeNoiseScale, 2);
                    float worleyFBM = shape.g * 0.625 + shape.b * 0.25 + shape.a * 0.125;
                    float baseCloud = saturate(worleyFBM * 0.5 + shape.r * 0.5);
                    //float baseCloud = remap(shape.r, worleyFBM - 1.0, 1.0, 0.0, 1.0);
                    totalShapeMod += baseCloud;
                }

                totalCoverage /= sampleCount;
                totalShapeMod /= sampleCount;

                // ShapeNoise在coverage基础上做浮动，增加细节层次和风动感
                float density = totalCoverage * lerp(0.7, 1.3, totalShapeMod);

                float shadowFactor = lerp(1.0, 1.0 - _CloudShadowStrength, saturate(density));
                sceneColor.rgb *= shadowFactor;

                return sceneColor;
            }
            ENDHLSL
        }
        //Pass 2: GodRays
        Pass
        {
            Name "GodRays"
            ZTest Always ZWrite Off Cull Off
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            float4 _SunScreenPos;      // xy=太阳屏幕viewport坐标, z=太阳是否在相机前方(>0代表在前方)
            float _GodRayDensity;
            float _GodRayDecay;
            float _GodRayWeight;
            float _GodRayIntensity;
            int   _GodRaySampleCount;
            float _GodRayObjectContribution;
           
            float4 frag(Varyings input) : SV_Target
            {
                float2 uv = input.uv;
                float4 sceneColor = SAMPLE_TEXTURE2D(_MainTex, sampler_MainTex, uv);
                
                // 太阳在相机背后时，直接不做光柱效果
                if (_SunScreenPos.z <= 0.0) 
                {
                    return sceneColor;
                }
                float2 sunUV = _SunScreenPos.xy;
                float2 noiseUV = uv * _ScreenParams.xy * _BlueNoiseTex_TexelSize.xy;
                float jitter = SAMPLE_TEXTURE2D(_BlueNoiseTex, sampler_BlueNoiseTex, noiseUV * _BlueNoiseTileScale).r;

                float2 deltaUV = (uv - sunUV) * (_GodRayDensity / (float)_GodRaySampleCount);
                float2 samplePos = uv - deltaUV * jitter; // 起点加上抖动偏移，而不是每次都从uv本身开始

                // float2 deltaUV = (uv - sunUV) * (_GodRayDensity / (float)_GodRaySampleCount);
                // float2 samplePos = uv;
                float illuminationDecay = 1.0;
                float3 result = 0;

                [loop]
                for (int i = 0; i < _GodRaySampleCount; i++)
                {
                    samplePos -= deltaUV;

                    // 超出屏幕范围就不再采样，避免边缘拉伸出奇怪的颜色
                    if (samplePos.x < 0.0 || samplePos.x > 1.0 || samplePos.y < 0.0 || samplePos.y > 1.0) break;

                    float sampleDepth = SampleSceneDepth(samplePos);
                    bool sampleIsSky = false;
                    #if defined(UNITY_REVERSED_Z)
                        if (sampleDepth <= 0.00001) sampleIsSky = true;
                    #else
                        if (sampleDepth >= 0.99999) sampleIsSky = true;
                    #endif

                    // 天空/云的采样点权重为1，物体采样点权重按_GodRayObjectContribution削弱
                    float sampleWeight = sampleIsSky ? 1.0 : _GodRayObjectContribution;

                    float3 sceneSample = SAMPLE_TEXTURE2D_LOD(_MainTex, sampler_MainTex, samplePos, 0).rgb;
                    result += sceneSample * illuminationDecay * _GodRayWeight * sampleWeight;
                    illuminationDecay *= _GodRayDecay;
                }

                result *= _GodRayIntensity / (float)_GodRaySampleCount;

                return float4(sceneColor.rgb + result, sceneColor.a);
            }
            ENDHLSL
        }


    }
```
