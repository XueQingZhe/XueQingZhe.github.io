# 包围盒

## AABB

**AABB** — Axis-Aligned Bounding Box，轴对齐包围盒。这里我实现的是AABB，后续在添加旋转控制\*\*
"轴对齐"意思是盒子的六个面永远平行于世界坐标系的XYZ轴，不能旋转。这就是为什么代码里能用简单的min/max做求交——每个面都垂直于某一个轴，数学极其简单。

## OBB

**OBB** — Oriented Bounding Box，有向包围盒。
允许任意旋转，盒子可以斜着放，贴合物体形状更紧密。

两者对比：

| AABB  | OBB           |                |
| ----- | ------------- | -------------- |
| 旋转    | 不能旋转，永远轴对齐    | 任意旋转           |
| 求交复杂度 | 极简单（就是你现在的代码） | 复杂（需要分离轴定理SAT） |
| 贴合度   | 差（斜放物体会有大量空白） | 好              |
| 用途    | 体积雾、碰撞粗检测、BVH | 精确碰撞、物理引擎      |

# 射线与AABB求交集

**因为公式是射线的表达式是：**

$$
r(t) = o + t·d
$$

这里就直接求解：

$$
o + t_0·d = boundsMin
$$

$$
o + t_1·d = boundsMax
$$

**因为保证交点在box内部，所以射线到box最近点是tmin取最大，最远点tmax则取最小**
![](/published-assets/08ab69e27285e6f1f0e2e37e3ffb7a890045b06c8cc5240d80c9c2b42dcfd255.webp)
