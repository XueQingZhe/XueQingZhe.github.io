# 文章发布管理器

双击 `F:\MyWeb\文章发布管理器.cmd`。先在「网站内容」清单中查找现有文章；需要导入新内容时再打开笔记库。页面底部的操作栏会显示当前下一步。

## 修改文章与封面

点击条目旁的「发布设置」，从已有分类、系列和 Tag 中选择。标签忽略大小写，例如 `Shader` 和 `shader` 是同一个标签。未设置明确学习方向的随记和研习文章归入「我独自升级」；明确的 Unity、UE、Blender 内容进入对应方向。手记仍是全部公开内容的索引。

封面选择默认读取当前文章的图片和视频。选择视频后，作品卡片在鼠标悬停时静音播放；选择图片则使用静态封面。需要其它文章的素材时，可主动切换素材来源。

## 管理作品合集

点击「管理合集」或「新建作品合集」。合集有自己的标题、简介和封面，成员保留各自的网址。从现有文章中加入成员，再拖动或用上移、下移调整阅读顺序。

合集封面默认从成员文章的素材中挑选，也可使用首篇文章的封面。视频和静态海报会一起保存；「改用静态封面」可停止卡片的视频预览。移除一个成员只解除合集关联。

## 从网站移除与恢复

在条目旁选择「从网站移除」，也可勾选多篇后批量操作。确认区会列出本次处理的文章。待移除条目会保留在清单中，写入前可以撤销。

完成本地写入后，文章会从网站索引、目录、搜索和公开文章页中撤下。原始笔记保留；在「已移除」筛选中可以恢复原网址与合集顺序。移除合集只移除合集入口，成员文章仍保留。

## 预览与上线

保存设置后，按底部操作栏完成检查。附件可按类型和大小筛选，批量选择压缩策略并确认，再生成副本、写入本地预览。确认区会单独标明移除和恢复的内容。

预览满意后点击「发布到 GitHub Pages」。本地保存和预览不会自动上传；部署完成后线上网站才会更新。

## 关联原有文章

笔记库中的「网站已有·待关联」表示找到候选文章。打开笔记设置，在「与网站已有文章关联」中确认目标并保留原网址。后续正文更新会沿用这个网址；不会仅凭相近标题覆盖文章。
