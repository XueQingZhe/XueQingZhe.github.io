## 画面完整性修复

## 当前动态

- SVG 以统一镜头移动完整画面，不使人物和背景分别移动。
- 日夜通过页面底色进行淡出/淡入，两个不同姿势的人物不会同时显现。
- 夜间仅在一小片无石阶、人物及花朵的水面进行亚像素位移。SVG 滤镜将噪声限定到柔边水域遮罩，遮罩外使用中性位移值；不叠第二张水面图片。
- 波动阳光、微光、飘落花瓣由轻量 WebGL 叠加呈现，独立于原图。失去 WebGL 时 SVG 原画和主题切换继续可用。
- 点击场景触发阵风，影响空气中的花瓣与光尘。当前不再形变头发、衣裙，也不使用生成眼部贴片眨眼。
- 暂停冻结动态时钟和镜头，仍可切换主题；减少动态效果时停止连续动画且水面位移为零。离屏和隐藏标签页不连续更新。

手机使用纯色文字区域、完整插画区域、导航区域。只在整幅插画上下外边缘向页面底色淡化，不淡化单独的人物轮廓。光效画布在手机上与插画区域同位置、同尺寸。

## 实现
