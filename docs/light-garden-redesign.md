## 首页与页面结构

首页是一处可交互的实时场景入口，主标题为“浮光游境”。书写体中文、印章式署名与大尺度英文文字共同组织首屏，四个入口分别是“造境 / WORK”“拾光 / JOURNAL”“寻径 / STUDY”“回声 / ABOUT”。入口悬停或键盘聚焦会改变场景观察方向与短句；细指针设备还提供轻微磁吸反馈和英文字重变化。移动指针拨动水光，触摸空白场景可触发短暂涟漪。

各页面使用独立构图和场景：

- 作品页：漂浮画框与几何雕塑，配合大字 WORK 和错落作品网格；支持引擎、技术、角色组合筛选，并将选择写入 URL。
- 手记页：漂浮纸页、流动线条与 JOURNAL 标题；按年份组织文章，支持关键词查询、标签与空结果状态。
- 学习页：环绕晶体的轨道装置，以及可点击的学习轨道图；串联“我独自升级”和星见雅 Blender、Unity、UE 教程。
- 关于页：树木小岛、微光与星点连线，保留真实的学习者定位、个人介绍和联系方式。
- 搜索页：雷达式线索视觉与本地全文搜索。`/` 快捷键可打开搜索。
- 作品与文章详情：保留项目图像、代码、公式、目录、阅读进度、图片灯箱及代码复制，正文保持稳定阅读。

## 原创实时图形与动效

`LivingScene` 使用 Three.js 构建原创几何、植物、灯光和水面。拱门、树叶、石材纹理、光点与天空均由代码生成；场景不加载用户提供的参考插画，也不把它们用作纹理。作品文章中的原有工程截图继续作为内容呈现。

水面使用 Reflector 和自定义着色器，包含场景倒影、轻微波动、受控焦散与指针涟漪。日间以青绿水光、柔和暖阳和植物阴影为主；夜间降低环境亮度，保留蓝绿色空间层次、灯光与少量漂浮光点。天空与远处水面共用线性色彩计算，经过色调映射，减少远景接缝和过亮的水面。

标题动效由 GSAP、SplitText 与 ScrollTrigger 驱动：等待字体加载后逐字遮罩入场，中文书写体带轻微旋转和悬停起伏，英文采用更利落的位移与变量字重反馈。内容块只在进入视口时显现。浏览器支持时使用原生跨文档 View Transitions；普通链接保留正常页面导航，无需 React 或客户端路由运行时。

渲染目标为最高 30 FPS，设备像素比限制为 1.5；窄屏进一步降低分辨率。场景离屏、页面进入后台或用户暂停时停止连续渲染，并在元素移除时释放几何、材质、纹理及渲染资源。日夜偏好与暂停状态保存在浏览器本地。系统设置“减少动态效果”时，文字直接进入最终状态，场景停止持续运动。

WebGL 不可用或上下文丢失时显示由 CSS 绘制的静态场景；四个入口与正文功能仍可使用。

## 字体与内容保留

中文艺术标题使用本地 Ma Shan Zheng 书写体（`expressive-chinese.woff2`，400 字重，330,572 字节）。字体当前包含 876 个 cmap 字符，877 个请求字符中唯一未包含的是中点 U+00B7；全部现有 Astro UI 汉字、首页标题和内页书写体副标题均已覆盖。独立 Chromium 实际渲染检查确认“浮光游境、造境、拾光、寻径、回声、雪轻遮、作品档案、思绪沉积、学习轨道、关于我”等文字使用自托管 `MaShanZheng-Regular`。

英文大字、数字和部分界面文字使用 Space Grotesk（`space-grotesk.woff2`，变量字重 300–700，22,288 字节）；中文正文使用系统无衬线字体。两款字体的 SIL OFL 1.1 授权、来源、SHA-256 与字形检查记录位于 `public/fonts`，最终数据见 `motion-font-provenance.json`。新增书写体汉字时需要同步更新子集。

保留 8 件公开作品、26 篇手记、38 个教程章节以及 60 个历史文章 URL；原有草稿保持不公开。项目截图、代码、数学公式、RSS、旧链接和内容集合继续沿用。旧站仓库 `F:\MyWeb\MyBlog\XueQingZhe.github.io` 的现有本地修改保持原状。

最终 Edge / Playwright 报告 `work/immersive-check.json` 的 11 项检查全部通过，`errors` 与 `failed` 均为空，覆盖：

- 原创入口 WebGL 正常渲染、帧持续更新、首页无插画图片、四个入口可用。
- 入口悬停反馈、日夜切换及偏好保持。
- 暂停后停止帧更新，刷新仍保持暂停。
- 作品、手记、学习、关于页分别加载正确的独立场景，并保留导航和暂停控件。
- 作品筛选刷新后保持，重置恢复 8 件作品；手记查询、空结果与重置恢复 26 篇文章。
- 全文搜索、作品详情图片灯箱与 Escape 关闭。

- 减少动态效果时标题不拆分、场景稳定；无脚本错误和缺失资源；禁用 WebGL 后静态入口仍可使用。
