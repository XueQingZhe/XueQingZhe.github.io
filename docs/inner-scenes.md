# 栏目中的立体装置

`FlowerStage.astro` 负责内页首屏与可访问控件，`flower-stage.ts` 用 Three.js/WebGL2 实时渲染四种空间装置。它们不替换花信入口的完整 SVG 插画。

- 作品：连续折带曲面，釉白、金属、网格三种材质观察。
- 手记：带文字纹理与厚度的书册；按钮触发网格弯曲翻页。
- 研习：黄铜星仪、旋转环、四个可选择卫星。系列名称和链接取自真实目录 DOM，遵循内容实际顺序。
- 关于：九片有厚度的光圈叶片与虹彩镜片，按钮控制开合。

共同使用透视相机、环境反射、方向光、实时阴影。鼠标/触摸水平拖动和方向键可旋转视角，复位按钮恢复初始相机。页面保留垂直触摸滚动；不抢占滚轮缩放。桌面与手机使用不同视角范围。

每页只建立一个场景。刻度使用 InstancedMesh 合并；设备像素比上限 1.5，渲染频率约 30 fps。离开可见范围、隐藏页面或暂停动效时停止持续渲染。减少动态效果偏好下按键直接到目标姿态。页面卸载释放几何体、纹理与渲染器。WebGL 不可用或上下文丢失时保留 SVG 静态构图和全部文章导航。

`[data-flower-stage].getSceneDiagnostics()` 提供本地验证用的帧数、时间、相机、绘制调用数与交互状态。`work/verify-flower-interaction.mjs` 验证拖拽、材质、翻页、光圈、目录链接、暂停、减少动效、上下文恢复与手机宽度。它使用本机 Edge，不是生产依赖。

设计按栏目采用暖金、纸紫、深蓝/鸢尾、玫瑰色。文章正文仍以可读性为主，保留目录、数学公式、图片查看、代码复制及原有内容。
