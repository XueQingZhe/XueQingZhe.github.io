# 浮光游境 · 水庭入口增强

本轮深化主页水庭，沿用原创二维绘画与 Three.js 空间组合。源码在 `F:\MyWeb\astro-site`，本地预览为 <http://127.0.0.1:4325/>。修改前备份位于 `F:\MyWeb\backups\before-portal-garden-v4-20260920`。

## 新增场景

- 近景：垂挂的米白与淡紫花序、杏白岸花、细芦苇、疏密不一的草叶和河石。花叶随风轻晃，石岸边缘没入水中。
- 中景：拱门旁两盏细铜骨吊灯，灯笼与柔光一起轻摆；夜间转为低亮度琥珀色。
- 远景：淡灰蓝岸线承接远树，保留水面的留白与深度。
- 水中：三条原创绘制的锦鲤缓慢游动，尾部独立摆动；指针靠近时略微聚拢，点击或触摸水面时短暂散开。
- 空中：两只小蝴蝶在白天绕门飞行，入夜渐隐。

花叶、石材、鱼和蝶的纹理由 Canvas 原创绘制，没有使用参考插画作为网页背景或纹理。景物按近、中、远层次放入三维空间，继续使用水面实时反射。

## 光束与交互

上帝光增加轻微的方向漂移、柔边游移、宽度伸缩与明暗起伏，并叠加缓慢掠过的疏影。三束光采用错开的节奏，上方光源保持稳定，主要由下方光束发生变化。夜间光束时钟降为日间的 60%，光束透明度降为日间的 29%。

鼠标点击与手机轻触水面都可泛起涟漪。新增景物与光束遵守“风正在吹／风暂时停了”控制和系统的“减少动态效果”；页面隐藏时停止连续绘制。暂停期间切换日夜仍可完成光色过渡，光束时间不推进。

## 实现位置

- `src/scripts/portal-scenery.ts`：石岸、河石、草叶、铜灯和远岸。
- `src/scripts/portal-flora.ts`：原创花序与岸边花草。
- `src/scripts/pond-life.ts`：游鱼、蝶翼绘制及行为。
- `src/scripts/living-scene.ts`：主页接入、光束着色器、触控交互和资源释放。

新景物仅加载在主页；光束的轻微波动沿用各分区既有光照。新增模块共用场景渲染循环，无额外动画循环、外部资源请求或 npm 依赖。离开页面时统一释放几何体、材质和纹理。

## 验证与预览

严格 TypeScript 检查、生产构建和站点检查已通过：79 个页面生成，70 页进入全文搜索，60 个历史 URL 均可用，站点检查未发现资源缺失或公式错误。

Edge / Playwright 验证了日夜切换与持久化、暂停后精确帧数与光束时间冻结、恢复动效、暂停时切换日夜、系统减少动态效果、真实触屏事件触发涟漪，以及 360／390／1440 像素宽度无横向溢出。四个入口均到达对应页面，作品页仍有 8 件作品，内页不加载主页新增景物。

检查中发现原生跨文档转场的 opt-in 识别时机不稳定，已将声明从外部样式表移到 `Base.astro` 的页面头部。修复后的四个入口定向复测均完成原生转场，未出现页面错误或控制台错误；最终报告区分完整首轮与此次定向复测，原始报告也保留。

桌面本机短时自动化采样约为 26.7 帧／秒，场景目标上限为 30 帧／秒；此数值不代表真实手机或不同 GPU 的性能。已目检日间、夜间及手机截图，分享预览图也更新为当前场景。
