# 网站文章同步与作品专题

双击 `F:\MyWeb\文章发布管理器.cmd`，使用新打开的管理器窗口。启动器会自动找到最新版服务。

## 网站已有文章

展开「网站现有内容与作品专题」，可按标题、网址和栏目查找网站已有内容。扫描同时读取网站源文章和发布器生成的副本。

笔记列表中的「网站已有·待关联」表示找到了候选，并不表示它已被发布器接管。打开该笔记的「设置」，在「与网站已有文章关联」中选择网站文章，点击「关联并保留原网址」。同名、旧版、修订版需要根据正文确认；发布器不会自动用近似匹配覆盖文章。

关联会继承网站的标题、栏目、摘要、封面与专题关系；笔记已有属性和明确设置仍优先。随后按原有流程分析、审核附件、生成副本和写入。网站显示更新后的内容并保留原网址，原始网站文件和笔记文件均保留。

已有生成记录也会核对网站文件是否真实存在、是否改变。旧记录缺少文件校验信息时显示「已有副本·待校验」，重新生成后完成校验。

## 调整作品专题

在网站内容清单中点击作品的「编辑专题」，或在「编辑作品专题」下拉菜单选择它。UE5.5 专题会载入现有三篇关联文章。

可编辑标题与摘要，从已有文章中选择子文章，再用「上移」「下移」「移除」调整顺序。新笔记先在目录中勾选并「保存选择与设置」，就能出现在关联文章的候选列表中。移除只解除专题关联，不删除文章。

点击「暂存专题设置」后，继续「分析本次副本 → 生成待预览副本 → 确认写入本地网站」。审核区会列出专题及文章顺序。暂存设置存放在本机私有目录，只有写入后才进入网站的 `src/data/publisher-topics.json`。

网站专题页、文章页的所属专题及专题上一篇／下一篇会使用相同顺序。预览满意后，再通过「发布到 GitHub Pages」更新线上网站。
