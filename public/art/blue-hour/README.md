# 蓝时花信 · 原创分层角色

四张透明、同坐标、可由 `THREE.TextureLoader` 直接加载的原生 SVG。画面为成年原创角色：松散低束长靛蓝发、象牙长裙、宽袖，侧坐捧着打开的小本子，神情安静。全部轮廓、五官、手部、衣褶与装饰由矢量曲线绘制；不使用参考图抠图、外部位图、字体、`foreignObject` 或外链。

## 合成

画布均为 **900 × 1100**，`viewBox="0 0 900 1100"`。所有层使用完全相同的平面大小、位置及 UV。由后向前：

1. `character-back-hair.svg` — 后发、低束长发及发梢。
2. `character-body.svg` — 坐姿裙体、躯干、双臂、双手、脸、颈、书与静态腰带。
3. `character-front-hair.svg` — 分缕侧分刘海、面侧发束与花形发饰。
4. `character-ribbon.svg` — 发束系带、向右飘起的两条窄缎带。

书和手已放在腰带之前，避免前层腰带遮住阅读动作。body 内含非常轻微的 SVG 颜料颗粒滤镜。四张 SVG 已经 Chromium 图片解码并叠加检查。

## 锚点（像素）

- 头部中心：`(450, 210)`；面部中心约 `(448, 233)`。
- 目线中点：`(439, 220)`；朝画面左侧。
- 后发低束 / 发带固定点：`(566, 436)`。
- 胸口：`(451, 405)`；腰线：`(460, 524)`。
- 书本中心：`(451, 580)`。
- 左侧握书手：`(390, 553)`；右侧托书手：`(501, 596)`。
- 坐姿右膝体积中心：`(623, 708)`。
- 裙底中心：`(480, 1003)`；轮廓范围约 `x153…800, y76…1024`。

若平面高度为 `H`，宽度为 `H * 900 / 1100`；像素锚点 `(x,y)` 转平面坐标为 `((x - 450) / 1100 * H, (550 - y) / 1100 * H)`。裙底可被前景花遮住 30–90 像素以融入花田。

## 动态建议

脸与身体应锁定在同一平面，前发仅作极轻移动，防止面侧发束离开脸部。后发可从固定束点附近缓慢摆动；发带单独柔和摆动。四层深度只需微小差值，避免转动相机后撕开角色。推荐透明材质、`depthWrite: false`、sRGB 贴图；保留边缘抗锯齿，不使用高 alphaTest 阈值。日夜通过整体低强度色温/亮度调整匹配环境即可，不必重画五官。
