# GitHub Pages 发布准备 · 2026-09-20

本次准备的是水亭主题，以及作品展示、阅读体验和文章管理器的最终改进。正式域名沿用 `https://xueqingzhe.github.io/`。

## 发布方式

源文件在 `main`，静态产物在 `gh-pages`。新的 `.github/workflows/deploy.yml` 使用 Node.js 22、`npm ci`、发布器测试、Astro、Pagefind、站内检查和产物检查。只有 `main` 的推送或手动运行能够部署；PR 只检查。Pages 继续使用 `gh-pages / (root)`，没有依赖新的 Pages 授权方式。

站点内已添加 `.nojekyll`、`robots.txt` 和 sitemap。保留旧项目重定向与 60 个旧文章地址。发布工具、私有笔记库、选择清单、缓存及 `work/` 都不会进入静态产物。

## 发布器修复

- 笔记身份：有歧义的同内容文件移动不再自动继承公开选择；手动关联后必须重新审核。
- 引用：按明确的相对路径解析附件，检查真正渲染的标题与段落锚点，正确处理文件名里的编码字符。
- 操作：处理期间锁定控件，重新扫描保留未保存的选择，根目录筛选正常，写入后清除过期审核状态。
- 恢复：文章、附件、清单和网站预览纳入同一个恢复事务；构建失败、预览切换失败和中断重启均可恢复。
- 启动：统一预览端口 4325；用服务身份确认端口归属，不再把任意占用端口当成正确网站。
