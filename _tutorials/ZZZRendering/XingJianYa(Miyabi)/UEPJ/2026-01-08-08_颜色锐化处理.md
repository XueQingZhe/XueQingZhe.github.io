## 颜色锐化处理

### 计算遮蔽信息

![](/assets/img/ZZZRendering/Pasted image 20250315163650.png)
***NDotL，顶点法线的兰伯特非常光滑细节较少***
![](/assets/img/ZZZRendering/Pasted image 20250315162924.png)
***pixelNDotL，含贴图法线发兰伯特拥有很多细节***
![](/assets/img/ZZZRendering/Pasted image 20250315162948.png)
***NDotL - pixelNDotL，两者相减可以得到物体的凹凸信息，那么用1减去这个值就可以得到一个遮罩的遮蔽信息occlusion***
![](/assets/img/ZZZRendering/Pasted image 20250315163200.png)
***1 -  (NDotL - pixelNDotL)***
![](/assets/img/ZZZRendering/Pasted image 20250315163803.png)
***当前遮蔽信息还是不够强烈所以先乘上3在用1减去，这样增强效果，这里乘以几都可以，可以随意调整，以效果为主,最后进行钳制防止有小于零的值***
***saturate((1 - 3 * (NDotL - pixelNDotL)))***
![](/assets/img/ZZZRendering/Pasted image 20250315163850.png)
***occlusion的杂色太多了，所以整体提亮2倍，去除一些杂色，只保留较小的信息，这里乘几同样也是经验值类的，自己随意调整以效果为准***
***(saturate((1 - 3 * (NDotL - pixelNDotL))) * 2***
![](/assets/img/ZZZRendering/Pasted image 20250315164013.png)
***进行pow(occlusion，1.5)，pow的作用就增加对比度，亮度更亮暗的更暗，最后在钳制防止超过1***
![](/assets/img/ZZZRendering/Pasted image 20250315164107.png)

***最后计算获得一个颜色衰减值，兰伯特的值是-1~1，这里使用半兰伯特0~1和遮罩系数进行计算是为了保留教暗地方的依旧有颜色衰减值，我们默认使用的是兰伯特光照，所以这里进行混合，使用0.5也就是均匀混合。这样就得到了一个颜色的衰减值，注意这里说的衰减值是作用于Gamma矫正也就是颜色变化，而不是仅仅亮度变化，这里叫做颜色Gamma矫正衰减系数应该比较合适***
![](/assets/img/ZZZRendering/Pasted image 20250315164246.png)

#### 计算颜色亮度和gamma值

***有了颜色Gamma矫正衰减系数，然后知道Gamma矫正的值后，就可以对颜色进行Gamma矫正了，但在这之前需要钳制颜色亮度，因为Gamma其实本质可以理解为Pow(Color，gamma)，对于大于1的进行Pow会导致变得非常亮***
***这里对颜色各个分量取得最大值，如果大于1，就将整个颜色除以这个值进行压暗，保证颜色不变的情况下降低明度，钳制到1以下**
![](/assets/img/ZZZRendering/Pasted image 20250315164449.png)

***这里Luminance()函数是根据权重计算颜色的灰度（亮度）值。最终通过灰度值来控制Gmma值基数，使用颜色Gamma矫正衰减系数混合，这里这个乘 0.2875和加1.4375的操作也属于经验值，并不是固定的，以效果为准***
***Desaturated节点默认参数下和Luminance效果一致***
![](/assets/img/ZZZRendering/Pasted image 20250315165215.png)
***Desaturated节点和默认参数***
***DesaturatedColor = (1 - Fraction) * Color + Fraction * Luminance***
![](/assets/img/ZZZRendering/Pasted image 20250315164941.png)
***Luminance节点***
***Luminance = 0.3 * R +  0.59 * G + 0.11 * B***

***现在有了Gama值后，现在就进行颜色的Gamma矫正了。直接使用pow即可，钳制一下不要等于0了，根据效果来调整强度，使用兰伯特控制，亮的部分就使用Gamma，暗的地方就减小Gamma强使用GammaHalf***
![](/assets/img/ZZZRendering/Pasted image 20250315165336.png)
